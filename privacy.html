Политика конфиденциальности

Приложение: hermes-main. Дата вступления в силу: 17 ноября 2026 года.

1. Кто обрабатывает данные

Приложение hermes-main используется одним физическим лицом — владельцем аккаунта Google, который его установил. Приложение не является публичным сервисом и не обслуживает иных пользователей. Контакт для любых вопросов: molina.tina.u@gmail.com.

2. Какие данные обрабатываются

  • Gmail: заголовки, текст писем, вложения — чтение, поиск, отправка и ответы по команде владельца;
  • Google Календарь: события, участники, напоминания — чтение и запись;
  • Google Контакты: имена, адреса почты, телефоны — чтение и создание;
  • Google Диск, Документы, Таблицы: файлы в объёме выданных разрешений.

Приложение не собирает данные иных лиц, не имеет доступа к данным других пользователей Google и не получает пароль от аккаунта.

3. Цель обработки

Единственная цель — выполнение задач, которые владелец аккаунта ставит приложению напрямую: подготовка сводок расписания, создание и изменение событий, поиск и отправка писем, ведение контактов и работа с файлами.

4. Авторизация и хранение

  • Доступ предоставляется по протоколу OAuth 2.0 на экране согласия Google.
  • Полученные токены доступа хранятся только на компьютере владельца и защищены средствами операционной системы.
  • Внешних серверов, облачных хранилищ приложения и резервных копий данных на стороне разработчика не существует.
  • Приложение не передаёт данные третьим лицам, не продаёт их и не использует для рекламы, профилирования или обучения моделей.

5. Хранение и удаление

Приложение не создаёт собственных копий данных Google: письма, события и контакты остаются в аккаунте владельца. Локальные токены удаляются вместе с приложением. Доступ приложения к аккаунту отзывается в любой момент на странице myaccount.google.com/permissions; после отзыва приложение теряет возможность читать или изменять данные.

6. Использование данных Google и Limited Use

Приложение использует данные, полученные через API Google, исключительно для функций, видимых владельцу аккаунта, и в соответствии с Google API Services User Data Policy, включая требования Limited Use. Данные не передаются третьим лицам, кроме случаев, когда это необходимо для предоставления функции по прямому запросу владельца, требуется законом или является частью обезличенной технической диагностики.

7. Изменения политики

Актуальная версия политики всегда доступна по этому адресу. Существенные изменения отражаются в дате вступления в силу.
